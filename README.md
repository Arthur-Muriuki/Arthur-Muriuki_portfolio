ARTHUR MURIUKI PORTFOLIO REFRESH

Files:
- index.html: redesigned one-page portfolio with SEO metadata and Person structured data
- style.css: responsive dark navy / purple visual refresh
- script.js: mobile navigation, typing effect, reveal animations, year and success notice
- robots.txt and sitemap.xml: starter technical SEO files

BEFORE DEPLOYING:
1. Copy your existing profile photo to assets/images/profile-image.jpg, or change the image src in index.html.
2. Replace YOUR_EMAIL@example.com in the contact form action with the inbox that should receive messages.
   FormSubmit may require you to confirm the receiving email the first time.
3. Create these favicon files and put them at the exact paths used in index.html:
   /favicon.ico
   /assets/images/favicon-32.png
   /assets/images/favicon-16.png
   /assets/images/apple-touch-icon.png
4. Create /assets/images/og-image.jpg (a social preview image, ideally 1200x630) or change/remove the Open Graph and Twitter image tags until it exists.
5. If you change hosts but keep the same domain, no canonical change is needed. If you later use a custom domain, update canonical, og:url, og:image, the sitemap and robots.txt together.
6. The current canonical URL and sitemap use your Netlify URL. Update them if your preferred public URL changes.

NOTES:
- A favicon does not have alt text. Use alt text on content images, like the profile portrait.
- This is a static site. The contact form uses FormSubmit as an external form delivery service; it does not send mail by itself.
- Project descriptions should accurately reflect your actual contribution. Adjust any stack labels if a project's final implementation differs.
