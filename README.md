# Arthur Muriuki — Developer Portfolio

[![Live Site](https://img.shields.io/badge/Live%20Site-Netlify-00C7B7?style=for-the-badge&logo=netlify&logoColor=white)](https://arthurmuriuki-portfolio.netlify.app/)

## Live Demo

Check out the live website: [arthurmuriuki-portfolio.netlify.app](https://arthurmuriuki-portfolio.netlify.app/)

---

## Features

- **Responsive & Accessible Design:** Built with modern CSS grid/flexbox layouts and accessible semantic HTML structure.
- **Dynamic Typing Effect:** Custom JavaScript typewriter animation in the hero section with `prefers-reduced-motion` support.
- **Interactive Navigation & UI:** Mobile toggle menu with keyboard navigation (Escape key support) and ambient UI elements.
- **AJAX Contact Form:** Powered by FormSubmit with async `fetch()` submissions, input validation, and automated auto-closing success popups.
- **SEO & Search Optimized:** 
  - Valid XML Sitemap (`sitemap.xml`)
  - Schema.org Structured Data (JSON-LD `Person` markup)
  - Custom Open Graph and Twitter Card metadata
  - Google Search Console integration ready
- **Lightweight & Fast:** Zero external frameworks or heavy dependencies for fast loading speeds and low latency.

---

## Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Variables & Modern Layouts), Vanilla JavaScript (ES6+)
- **Font Integration:** Google Fonts (*DM Mono*, *Manrope*)
- **Form Handling:** FormSubmit API (JSON endpoint via `fetch`)
- **Hosting & Deployment:** Netlify
